# CommandCabin v0.9.0

本次更新集中完成产品工程审计后的安全、稳定性、搜索体验和设置界面改造。

## 安全与隐私

- 为 launcher、截图和贴图窗口建立独立角色与最小 preload API。
- 所有 IPC 统一校验窗口角色、主 frame 和可信 renderer URL；导航、弹窗与 session 权限默认拒绝。
- Electron renderer 启用 sandbox。
- 第三方插件改为安全模式：允许检查和登记，但隔离运行时完成前不执行第三方主进程代码。
- 插件 UI session 默认拒绝权限，插件 manifest 返回不可变快照。
- 移除安装器中无所有权验证的旧目录递归删除。
- 在线翻译增加显式授权、IPC 同意校验、2000 字符上限和 POST 传输；失败时不再自动转发给第二家服务。

## 稳定性与性能

- 修复启动器重复搜索、旧选中项执行、结果数量与键盘模型不一致等问题。
- 修复搜索 `limit` 改变排序、高亮偏移和已持久化排序参数未生效的问题。
- 修复截图 ready 超时后无法再次截图、warm overlay 被截入画面、并发输出和图片加载失败问题。
- 修复动态汇率结果竞态、无效汇率和数值溢出。
- 三个全局快捷键在持久化前统一做唯一性校验。
- Start Menu 快捷方式改为有界并发解析；应用索引改为 single-flight。
- 图标缓存使用串行、同目录临时文件原子写入。
- SQLite transaction 拒绝异步 handler；插件数据防止特殊 key 原型污染。
- JSON 格式化会拒绝无法无损表示的大整数和非有限数值。
- 剪贴板历史保留原始空白，并在持久化失败后正确重试。

## 界面与功能

- 启动器首页完整展示 12 个应用，添加应用入口移至统一操作栏。
- 修复结果点击、键盘 Enter 和 Add App 对话框的交互冲突。
- 设置页改为可滚动响应式卡片布局，三个快捷键合并为一张设置表。
- 重新开放插件管理、收藏管理和数据目录设置。
- 插件管理页明确显示安全模式和第三方代码不执行状态。
- 截图 OCR/翻译/保存操作增加忙碌态和冲突操作禁用。

## 兼容性说明

- 已安装的第三方插件会保留记录，但升级后自动设为停用。
- 在独立、可终止的隔离插件运行时完成前，第三方插件命令不会执行。
- 本地数据目录和 SQLite 数据库位置保持不变。
- 当前 Windows beta 安装包未做代码签名，安装时可能出现 Windows SmartScreen 提示。
