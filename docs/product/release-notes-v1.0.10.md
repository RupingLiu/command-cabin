# CommandCabin v1.0.10

恢复独立单位换算页面，首页固定应用现在最多显示三行、15 个软件图标。

- 截图和识别文字按钮移到底部，腾出一行软件图标的空间。
- 保留图标大小和两行应用名称，兼顾不同 Windows 显示缩放比例。
- 第三行支持点击启动、方向键选择、Enter 打开、拖拽排序和右键取消固定。
- 更新提示出现时，图标区可滚动，键盘选择会自动显示选中的应用。
- 首页恢复“单位换算”按钮，可进入独立的重量、长度换算页面。
- 换算页恢复两侧输入、单位选择、交换单位和返回操作，沿用旧版的换算精度。

可在设置页检查更新，下载完成后点击“立即安装”，也可直接下载安装包。
安装包附带同名 `.sha512` 校验文件，可用于核对下载完整性。
安装包未签名，Windows 可能提示确认运行。
