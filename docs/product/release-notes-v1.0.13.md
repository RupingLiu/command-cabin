# CommandCabin v1.0.13

修复“检查更新”在部分网络下始终失败并显示 `HTTP 403` 的问题。

- 检查更新改用不会消耗 GitHub API 配额的通道，共享网络出口不再影响更新检查。
- 即使 API 配额耗尽，仍能正常发现新版本并下载安装包。
- 失败提示改为可读说明，并给出建议重试时间，不再只显示 `HTTP 403`。
- 修复失败后反复点击“检查更新”会连续重试的问题，现在需等待冷却结束。
- 自动检查在失败后自动退避，不再持续无效请求。

在设置页「检查更新」可发现新版本，下载完成后点击“立即安装”，也可直接下载安装包。
安装包附带同名 `.sha512` 校验文件，可用于核对下载完整性。
安装包未签名，Windows 可能提示确认运行。
