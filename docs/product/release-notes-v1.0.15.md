# CommandCabin v1.0.15

截图框更快出现，截图翻译支持选择目标语言，译文直接覆盖选区内的原文。

- 在首页点「截图翻译」，框选文字后按 `Enter`。普通截图也可以在框选后点「翻译」。文字识别在本机完成，触发翻译会将识别出的文字发送给 Google 翻译，每次最多 2000 个字符。
- 工具栏可选简体中文、繁體中文或 English，并记住上次选择。切换目标语言可用同一段原文重新翻译。点「撤销」可恢复原文，保存截图时会保留当前显示的译文。
- 加快双屏和高分辨率桌面的截图响应。可以框选时会显示「拖动框选 · Esc 取消」。修复直接框选文字时导出空图、导致识别失败的问题。
- 启动快捷键被其他程序占用时，仍可打开 CommandCabin 并在设置中更换快捷键。程序已在后台运行时，再次打开会唤出启动器。

已安装的用户可在设置页「检查更新」。手动下载请选择 `CommandCabin-Setup-1.0.15.exe`，随附的 `.sha512` 文件可用于校验下载。安装时 Windows SmartScreen 可能提示确认运行。
