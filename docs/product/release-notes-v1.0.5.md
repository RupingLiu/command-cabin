# CommandCabin v1.0.5

本次更新带来 A 方案「清晰原生」界面，并修复自动更新安装入口与搜索逻辑。

## 界面与操作

- 主窗口采用白灰底色与青绿色强调色，统一搜索框、收藏卡片、工具按钮和深色主题。
- 设置页增加常规、快捷键、收藏、数据与关于分类；切换页面时保存正在编辑的输入。
- 优化长应用名、文件路径、多语言与高 DPI 显示，保留键盘选择和结果自动滚动。

## 自动更新修复

- 更新请求支持代理环境变量及 Windows 手动系统代理，修复代理网络下安装包下载超时。
- 检查到新版本后自动下载；只有文件大小与 SHA512 校验通过，才显示安装按钮。
- 首页和搜索结果均显示下载进度及“立即安装”；设置的“关于”页同步显示安装状态。
- 安装入口改用 Windows 提权机制，修复普通权限下启动安装包报错 740 的问题；取消 UAC 后保留安装包，可再次安装。
- 检查或下载失败后可立即手动重试，不再被十分钟冷却拦住。
- 修复自动安装未正确恢复自定义安装目录的问题；文件无法替换或等待进程退出超时会停止安装。

## 搜索修复

- 历史或收藏加权不再带入与查询无关的结果，同一候选不会重复出现。
- 搜索标点按字面内容匹配。

## 从旧版升级

v1.0.4 及更早版本的安装入口存在权限问题。若“立即安装”报错，请下载本页的
`CommandCabin-Setup-1.0.5.exe` 并双击安装，或直接运行已经下载的安装包。
此问题由旧版本客户端触发，需要手动完成这一次升级；后续升级使用修复后的入口。
安装完成后应用会自动启动，用户数据保留。

安装包尚未进行代码签名，Windows 可能显示 SmartScreen 提示。
可用 `Get-FileHash .\CommandCabin-Setup-1.0.5.exe -Algorithm SHA512`
与同名 `.sha512` 文件核对完整性。
