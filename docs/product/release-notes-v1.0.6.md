# CommandCabin v1.0.6

修复从首页打开设置时，左侧导航栏、页标题和底部提示可能显示为空白的问题。

Windows 在窗口隐藏后可能清空显示缓冲区，而软件渲染器仍保留局部重绘缓存。
现在每次打开设置都会先刷新完整画面，再显示到窗口，确保静态区域一并绘制。
当前设置页、输入内容和用户配置保持原有行为。

新增回归验证覆盖显示缓冲区丢失后连续三次重新打开设置，逐像素检查侧栏、标题及页脚，并验证侧栏点击切换页面。

v1.0.5 用户可等待自动下载，完成后点击“立即安装”；也可手动下载安装包。
安装包尚未签名，Windows 可能显示 SmartScreen 提示。可使用同名 `.sha512` 文件核对完整性。
