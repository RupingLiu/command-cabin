# CommandCabin v1.0.7

修复启动器运行期间安装新软件后，搜索结果未更新的问题。

现在重新唤出启动器时会在后台刷新应用索引，并每 30 分钟自动刷新一次。
连续唤出采用 30 秒刷新间隔，同一次扫描不会重复启动；扫描完成后更新当前搜索结果。
索引内容未变化时保留当前结果选择，桌面与开始菜单中指向同一应用的快捷方式仍会合并。

新增回归测试覆盖运行期间新增和删除快捷方式、重复项合并、索引刷新后搜索结果更新，
以及收藏和系统命令保留。

v1.0.6 用户可等待自动下载，完成后点击“立即安装”；也可手动下载安装包。
安装包尚未签名，Windows 可能显示 SmartScreen 提示。可使用同名 `.sha512` 文件核对完整性。
