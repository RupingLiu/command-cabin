# CommandCabin v1.0.8

首页固定图标支持拖动排序和右键管理。

- 按住图标拖到目标位置，即可调整顺序，支持跨行移动；顺序自动保存，重启后保留。
- 拖动时显示图标预览和目标位置；按 Esc 或拖到网格外松开可取消，不会误启动应用。
- 右键点击图标，选择“取消固定”，即可从首页移除；应用仍可通过搜索打开。
- 自定义排序后，新固定的应用追加到末尾。尚未调整过的固定项沿用原来的名称排序。
- 设置页“返回”按钮采用无边框样式，文字水平、垂直居中，保留鼠标和键盘操作。

可在设置页检查更新，下载完成后点击“立即安装”，也可直接下载安装包。
安装包附带同名 `.sha512` 校验文件，可用于核对下载完整性。
