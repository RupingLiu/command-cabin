# v1.0.10 首页固定应用三行布局

## 问题与修复

用户指出首页截图与识别文字按钮下方留白过多，希望软件图标可多放一行，
并授权优化和测试完成后发布 Release。

原生首页从每行 5 个、最多 2 行扩为最多 3 行，共 15 个固定应用。图标与磁贴
尺寸保持不变，应用名称仍有两行空间。快捷操作区移至底部，适度收紧顶部边距
和分区间距，在原有 520px 窗口高度和 560px 最小宽度内完整显示三行。

固定磁贴改用一个按收藏顺序排列的模型，由 Slint 按下标计算行列；鼠标启动、
Enter 执行和键盘导航读取同一模型。第三行沿用拖拽排序和右键取消固定入口。
更新横幅占用空间时，图标区可滚动，键盘选中项自动进入可见区域；横幅消失
或收藏减少后，将滚动偏移限制回有效范围。

本次调整是用户要求的原生首页布局变化，不修改 TS 首页结果合成规则。
TS 参考 `apps/desktop/src/main/launcher/launcherCommandService.ts` 的
`SEARCH_RESULT_LIMIT = 10` 与 `listHomeAppSearchResults`；原生
`cabin-core/src/home/mod.rs` 的列表合成及 TS parity 行为保留。

- 真实 Slint 组件的软件渲染测试覆盖 560px、640px 宽度，100% / 150% / 200%
  缩放，以及浅色和深色；三行均完整显示，不需要增大窗口或缩小图标。
- 使用真实指针和按键事件，验证 15 个磁贴可点击、第三行下沿可点击、底部
  截图和识别文字按钮可用，以及第三行方向键导航和 Enter 执行。
- 验证第一行与第三行之间双向拖拽、第三行右键取消固定、更新横幅下的自动
  滚动、横幅消失后的布局恢复，以及收藏减少为一行或空时的滚动恢复。
- 原有两行拖拽、取消固定、搜索列表滚动、更新安装入口和系统主题测试继续覆盖。
- 单位换算页恢复后一同执行 `cargo test --workspace --locked --quiet`：
  684 通过，4 项默认忽略。
- `cargo clippy --workspace --locked -- -D warnings`、`cargo fmt --all -- --check`
  和 `git diff --check` 通过。
- 渲染截图和测试日志保存在本机 `native/artifacts/home-grid/`；测试窗口不注册
